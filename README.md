# Untitled Dungeon Crawler [Title TDB]

A 3D dungeon crawler where you fight with fast melee combat against rooms of monsters with a fixed camera and loot that makes each run feel different.

## Inspirations:

- Hades
- Hollow Knight
- Scaredy Cats (Kimbo)

## Tech

- Unity 6
- C#, new Input System
- CharacterController for player movement
